## 오늘 할 일

### 오전: 자기소개 페이지 네 단계

같은 자기소개 페이지를 네 단계에 걸쳐 고쳐 갑니다. 단계가 끝날 때마다 아래 두 줄로 commit(저장 지점)을 남깁니다. 따옴표 안의 메시지만 단계에 맞게 바꿉니다.

```bash
git add .
git commit -m "1단계 한 줄 요청으로 만든 자기소개 페이지"
```

- [ ] 1단계 한 줄 요청(덱 "한 줄 요청으로 만들기"): Codex 에 한 줄로 요청해 페이지를 만들고, 무엇이 생겼는지 Codex 답 아래의 바뀐 파일 묶음에서 봅니다. 새로 만든 파일은 VS Code 소스 제어(Source Control)에 `U` 표시로 보입니다. `uv run streamlit run 파일이름.py` 로 실행해(처음 실행할 때는 아래 "Streamlit 앱을 처음 실행할 때"를 봅니다) 자기소개 페이지 체크리스트로 채점하고, 아래 점수 표에 적은 뒤 commit 합니다
- [ ] 오류 읽기 연습(덱 "한 줄 요청으로 만들기"): `practice/day03_01_error_reading.ipynb` 의 A~C 묶음을 하고(일부러 오류를 내는 셀이 있어 셀을 하나씩 실행합니다. 모두 실행은 첫 오류 셀에서 멈춥니다), 이어서 `uv run streamlit run practice/broken_app.py` 로 고장 난 앱을 실행해 오류를 읽고 Codex 에 다시 요청합니다
- [ ] 2단계 요구사항과 검증(덱 "요구사항과 검증 루프"): 새 파일 `requirements.md` 맨 위에 내 값 세 가지를 적습니다. 이름, 전공(또는 공부한 분야), 관심 직무와 고른 이유 한 줄입니다(예: 이름 `홍길동`, 전공 `국어국문학`, 관심 직무 `UX 리서처`, 고른 이유 `사람들의 말을 듣고 서비스가 불편한 지점을 찾아내는 일이 즐거워서`). 이름을 적고, 연락처는 넣지 않습니다. 경험은 3단계에서 보태므로 지금은 적지 않습니다. 이어서 3줄 요구사항과 요구사항 체크리스트를 쓰고 Codex 로 다시 구현한 뒤 `/review` 를 확인합니다. Codex 의 자가 채점과 직접 확인한 결과를 비교합니다. 자기소개 페이지 체크리스트로 다시 채점해 점수 표에 적고 commit 합니다
- [ ] 3단계 빠진 항목 보완(덱 "MCP 활용"): 2단계 채점에서 아니요인 항목(보통 6번 경험)을 `requirements.md` 에 내 값으로 보완합니다. 내 정보에 경험을 적고 무엇을 했고 무엇을 배웠는지까지 씁니다. 요구사항 체크리스트에 경험 항목을 추가하고 2단계와 같은 요청을 다시 보냅니다. 예시와 요청은 문서 "3일차 실습 자료"의 05절에 있습니다. 자기소개 페이지 체크리스트로 다시 채점해 점수 표에 적고 commit 합니다. 시간이 남으면 같은 문서의 06절에 따라 Playwright MCP 를 연결해 Codex 가 내 페이지를 확인하게 합니다(선택)

### Streamlit 앱을 처음 실행할 때

처음 한 번은 터미널에 아래 안내가 나오고 `Email:` 에서 멈춥니다. 아무것도 적지 않고 Enter 를 누릅니다. 그러면 서버가 켜지고 브라우저에 페이지가 열립니다. 두 번째 실행부터는 묻지 않습니다.

```text
      👋 Welcome to Streamlit!

      If you'd like to receive helpful onboarding emails, news, offers, promotions,
      and the occasional swag, please enter your email address below. Otherwise,
      leave this field blank.

      Email:
```

- Enter 뒤에 나오는 사용 통계 안내와, 주소 아래의 `Help agents write better Streamlit apps?` 두 줄, 브라우저 오른쪽 위의 알림(Install, Don't show again)은 이 수업에서 쓰지 않으므로 무시합니다
- 브라우저가 열리지 않으면 터미널의 `Local URL:` 주소(`http://localhost:8501`)를 브라우저 주소 창에 붙여 넣습니다
- Windows 에서 처음 실행할 때 방화벽 허용 창이 뜨면 취소해도 됩니다. 내 컴퓨터의 브라우저(`localhost`)에서는 그대로 열립니다
