# 3일차 실습 저장소: 바이브코딩 기초

이 저장소에서 Codex 에 요청해 자기소개 웹 페이지를 만듭니다. 할 일 앱 과제도 합니다. 실습 순서는 강의 사이트의 "3일차 주강사 실습"과 "3일차 현장조교 실습" 문서에 있습니다.

## 어디서 시작하나

| 시간 | 파일 또는 폴더 | 하는 일 |
|---|---|---|
| 주강사 실습 | `practice/day03_02_intro_page.ipynb` | 자기소개 웹 페이지를 단계별로 만들고 채점합니다 |
| 주강사 실습 | `practice/day03_01_error_reading.ipynb` | 오류 메시지를 읽는 연습을 합니다 |
| 주강사 실습 | `.vercelignore` | 페이지를 배포할 때 뺄 파일 목록입니다. 새 폴더를 만들면 이 목록에 추가합니다 |
| 현장조교 실습 | `hw/day03_hw_todo_app.ipynb` | 할 일 앱을 만들어 확인한 뒤 제출합니다 |
| 현장조교 실습 | `todo/` | 요구사항, 확인용 입력, 화면 시안이 있습니다. 이 폴더에 앱(`todo/app.py`)도 만듭니다 |
