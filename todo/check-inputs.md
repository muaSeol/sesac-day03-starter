# 할 일 앱 확인용 입력

할 일 앱을 다 만들었으면 아래 입력 3개를 순서대로 넣어 결과를 확인하고, 이어서 기능 확인 다섯 가지를 합니다. 입력마다 "기대 결과"와 같은지 비교합니다. 다르면 무엇이 달랐는지와 화면을 Codex 에 알려 고치게 합니다(다시 요청하는 문장 틀: 지금 결과(실제로 본 화면이나 오류 메시지 전체), 기대한 결과, 고칠 곳).

## 시작 전 준비

- 저장소 폴더의 터미널에서 `uv run streamlit run todo/app.py` 로 앱을 실행합니다
- 이미 할 일이 들어 있어도 됩니다. 아래 기대 결과의 개수는 입력 전과 비교합니다
- 참고 화면은 강의 사이트의 문서 "3일차 과제형 실습"의 04절에 있습니다. 화면 시안과 참고 화면의 날짜와 할 일은 내 화면과 다를 수 있습니다

## 입력 1. 날짜를 고른 할 일

- 넣을 글: `3일차 실습 자료 미리 읽기`
- 하는 일: 달력에서 오늘 날짜가 골라진 상태에서 `할 일 제목` 칸에 붙여 넣고, `마감 날짜` 칸을 내일 날짜로 바꾼 뒤 `추가` 를 누릅니다
- 기대 결과
  - 달력에서 내일 날짜가 골라지고, 목록 제목이 내일 날짜(`12월 4일(금) 할 일` 꼴, 수업일 12-03 기준)로 바뀝니다
  - 목록 맨 아래에 `3일차 실습 자료 미리 읽기` 가 그대로 보입니다
  - `할 일 제목` 칸이 비워집니다
  - 달력의 내일 날짜 칸에 적힌 할 일 수가 1 늘어납니다(할 일이 없던 칸이면 `1개` 가 생깁니다)
- 참고 화면(강의 사이트의 3일차 과제형 실습): `d03-c9-input1.webp`

## 입력 2. 빈 제목

- 넣을 글: 없음(`할 일 제목` 칸을 비운 채)
- 하는 일: `할 일 제목` 칸에 아무것도 적지 않고 `추가` 를 누릅니다
- 기대 결과
  - `할 일 제목을 적어 주세요.` 가 경고로 보입니다
  - 목록, 개수 줄, 달력의 할 일 수가 그대로입니다(빈 줄이 추가되지 않음)
- 참고 화면(강의 사이트의 3일차 과제형 실습): `d03-c9-input2.webp`
- 더 해 보기: 띄어쓰기만 두세 칸 넣고 `추가` 를 눌러도 결과가 같아야 합니다

## 입력 3. 긴 제목

- 넣을 글(한 줄로 복사해 붙여 넣습니다. 맨 끝이 `(끝)` 입니다)

```text
다음 주 월요일 오전 9시 전까지 희망 직무를 하나 정하고, 미니 앱 아이디어 세 개를 대상 사용자와 해결할 문제와 핵심 기능으로 나눈 3줄 요구사항으로 적어 제출 양식에 올린 뒤, 그 가운데 하나를 첫 개인 프로젝트 주제로 고르기(끝)
```

- 하는 일: 달력에서 오늘 날짜를 누른 뒤, `마감 날짜` 는 그대로(오늘) 두고 붙여 넣어 `추가` 를 누릅니다
- 기대 결과
  - 오늘 목록 맨 아래에 추가되고, 줄이 바뀌어 맨 끝의 `(끝)` 까지 보입니다. 말줄임표(…)로 잘리지 않습니다
  - `할 일 제목` 칸이 비워지고, 개수 줄의 전체 수와 달력의 오늘 칸 할 일 수가 1 늘어납니다
- 참고 화면(강의 사이트의 3일차 과제형 실습): `d03-c9-input3.webp`

## 입력 뒤에 이어서 확인할 것

아래 다섯 가지를 순서대로 확인합니다. 괄호 안의 번호는 요구사항 체크리스트의 항목 번호입니다.

1. **완료 체크(8번)**: 달력에서 오늘 날짜를 누르고 `완료 확인용` 을 하나 추가한 뒤, 그 할 일의 체크 칸을 누릅니다. 그 제목에 취소선이 그어지고 흐린 색이 되며, 개수 줄의 완료 수가 1 늘어납니다(`완료 1개 / 전체 2개` 꼴. 이미 넣어 둔 할 일이 있으면 그만큼 많습니다). 한 번 더 누르면 완료가 풀립니다. 다시 눌러 완료로 둡니다. 참고 화면: `d03-c9-done.webp`
2. **수정(9번)**: 달력에서 내일 날짜를 누르고, 입력 1 의 할 일에서 `수정` 을 누릅니다. `할 일 수정` 창에 지금 제목과 마감 날짜가 채워져 있습니다. 제목을 `3일차 실습 자료 미리 읽고 질문 적기` 로 바꾸고 `저장` 하면 목록에 바뀐 제목이 보입니다. 한 번 더 `수정` 을 눌러 마감 날짜를 모레로 바꾸고 `저장` 하면 모레 날짜가 골라지고 그 목록에 보입니다. 달력의 내일 칸 수는 1 줄고 모레 칸 수는 1 늡니다. 참고 화면: `d03-c9-edit.webp`(제목을 바꾸는 중)
3. **삭제(10번)**: 달력에서 오늘 날짜를 누르고, 입력 3 의 긴 제목 할 일에서 `삭제` 를 누릅니다. `할 일 삭제` 창에 ` 이 할 일을 삭제할까요?` 와 그 제목이 보입니다. 먼저 `취소` 를 눌러 그대로 남는지 봅니다. 다시 `삭제` 를 눌러 창의 `삭제` 를 누르면 목록에서 사라지고 개수 줄의 전체 수와 달력의 오늘 칸 수가 1 줄어듭니다. 참고 화면: `d03-c9-delete.webp`
4. **보기와 달 이동(11번, 6번)**: `보기` 에서 `완료` 를 고르면 체크한 할 일(`완료 확인용` 등)만, `진행 중` 을 고르면 체크하지 않은 할 일만 보입니다. 체크하지 않은 할 일이 없으면 `진행 중인 할 일이 없습니다.` 가 보입니다. `전체` 로 되돌립니다. `다음 달` 을 누르면 달력의 연과 월이 한 달 뒤로 바뀌고, `이전 달` 을 누르면 돌아옵니다.
5. **껐다 켜기(12번)**: 터미널에서 Ctrl+C 로 앱을 끄고 같은 명령으로 다시 실행합니다. 할 일, 마감 날짜, 완료 표시가 그대로 남아 있습니다. `todo` 폴더 안에 `todos.db` 파일이 생겼는지 VS Code 탐색기에서 봅니다. 참고 화면: `d03-c9-restart.webp`
